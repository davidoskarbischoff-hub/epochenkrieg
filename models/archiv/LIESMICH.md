# Archiv
Hier liegen Modelle aus den hochgeladenen Paketen, die das Spiel im Moment **nicht** benutzt (aus `models/neu/` verschoben, Release 2).
Nichts wurde gelöscht. Um ein Modell wieder zu benutzen, im Manifest (`models/manifest.json`) einfach den Pfad `archiv/<Dateiname>` eintragen
oder die Datei zurück nach `models/neu/` schieben. Die Desktop-App nimmt nur Dateien mit, die im Manifest stehen.
